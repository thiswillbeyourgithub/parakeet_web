# 13.2.0 (2026-11-28)

## Interface

- The app now uses [Atkinson Hyperlegible Next](https://github.com/googlefonts/atkinson-hyperlegible-next), a font designed by the Braille Institute so that easily confused characters (like 0 and O, or 1, l and I) stay distinct. It is served by the app itself, so no request goes to a third-party font service.
- Buttons and input fields now use the same font as the rest of the page instead of the browser's default one.
